# 1.1 Overview

## What It Is

FC Career Hub is a web companion for FC 26 Career Mode. It lets a player track and shape the long arc of a manager save: the careers they're running, the clubs they've passed through, the squad they're building, the transfers they've completed, the seasons they've won, and the players they're chasing next.

The product is single-player by design — every save belongs to one user. There are no leagues, no shared rankings, no live match data. The app is a vault, a planning surface, and an AI-assisted scout — not a simulator.

## Who It's For

Career Mode players who:

- Run multiple long careers and want a clean place to remember them.
- Care about long-term history — clubs managed, trophies, season trails.
- Plan transfer windows deliberately rather than acting in-game on impulse.
- Want a smarter scouting flow than the in-game database provides.

## Core Value

- **Memory** — a save outlives a console upgrade or a corrupted game file. The career trail lives here.
- **Planning** — squad, finances, and transfers in one place, away from the chaos of the in-game UI.
- **Discovery** — search the full FC26 player dataset by any attribute, scored against your current squad's profile, with a chat assistant that knows your save.

## What Already Works (current repo)

- Account creation, sign-in, session management.
- Multiple saves per user; each save is a Career Mode career bound to a club.
- Squad management — add, edit, release players; track stats per season.
- Field lineup planner with formation picker.
- Transfer registry (incoming, outgoing, loans) that updates the save's balance.
- Team stats per competition per season; trophies; club stints.
- Change-club and new-season lifecycle actions with server-side cascade.
- Dashboard summary of the active save.
- Scout (paid) with FC26 dataset filters, fit-score, and an AI assistant ("Mister") that uses the Model Context Protocol to read the user's career data.
- Configurable scout playbooks (weighting profiles per save).
- Onboarding tours.

## What It Isn't

- Not a match simulator.
- Not a multiplayer experience.
- Not connected to EA's live game state.
- Not a fantasy-football overlay — it tracks the user's own subjective save, not real-world data.

## Why It Exists

Career Mode players already track their saves manually — spreadsheets, screenshots, Notion docs. The product is the dedicated tool that those workarounds want to be: structured around the actual lifecycle (save → club → season → squad → transfers → trophies) and enriched with the data and intelligence that no spreadsheet provides.

## Plans

Three tiers (see [`src/shared/config/plans.ts`](../../src/shared/config/plans.ts) and Prisma `UserPlan`):

- **FREE** — full hub access (saves, squad, transfers, stats, history, dashboard, new season, change club, tutorial).
- **PRO** — adds the entire Scout module (AI assistant, FC26 dataset filters, shortlist, saved searches, playbooks).
- **PREMIUM** — same access as PRO. (The split exists in the data model for future-proofing; the gating helper `canAccessProFeature` accepts either.)

Plan gating is enforced both at the route layer (`<PlanRoute />`) and at the navigation layer (sidebar hides Scout items for FREE).

## State of the Product

A functional, end-to-end careerhub MVP is in place: the API is deployed (Railway/Neon/Redis), the frontend is in production-ready shape, the FC26 dataset is loaded, the MCP-driven chat assistant works. Remaining work is mostly polish, coverage, and a small number of API capabilities not yet wired in the frontend (shortlist and saved-searches dedicated clients).
