# 3.2 Design System

## Philosophy

Dark-only, gamer aesthetic. The product reads as a Career Mode companion app — high contrast, neon-green accents, glow effects on stats, and condensed display typography. There is **no light theme** and no theme switcher.

## Tokens

All tokens are HSL CSS variables defined in [`src/index.css`](../../src/index.css) and exposed via Tailwind in [`tailwind.config.ts`](../../tailwind.config.ts). Always use the semantic class (`bg-primary`, `text-muted-foreground`) — never hardcode HSL or hex.

### Palette

| Token | HSL | Use |
|---|---|---|
| `--background` | `220 20% 7%` | App background — near-black navy. |
| `--foreground` | `210 20% 92%` | Default text. |
| `--card` | `220 18% 10%` | Card surface (slightly lighter than bg). |
| `--surface` | `220 16% 12%` | Secondary surface tier. |
| `--primary` | `142 70% 49%` | Neon green — primary actions, active nav, stat highlights. |
| `--accent` | `195 90% 50%` | Cyan — secondary accent, info. |
| `--destructive` | `0 72% 51%` | Errors, destructive actions, sign-out. |
| `--warning` | `38 92% 50%` | Warnings (custom token, used sparingly). |
| `--gold` | `45 93% 47%` | Premium / trophies. |
| `--muted` | `220 14% 14%` | Muted surface. |
| `--muted-foreground` | `215 12% 50%` | Secondary text. |
| `--border` | `220 14% 18%` | All borders. |
| `--ring` | `142 70% 49%` | Focus ring (matches primary). |

Sidebar has its own scoped token set (`--sidebar-background`, `--sidebar-foreground`, `--sidebar-primary`, `--sidebar-accent`, `--sidebar-border`, `--sidebar-ring`) so it can drift from card tones without affecting the main surface.

### Custom utilities
Defined in `src/index.css` `@layer utilities`:
- `.glow-primary` — `box-shadow: var(--glow-primary)` (soft green halo).
- `.glow-accent` — cyan halo.
- `.text-glow-primary` — text-shadow green glow for `.stat-highlight`.
- `.card-gamer` — bordered card with linear-gradient background.
- `.stat-highlight` — `text-primary font-display font-bold text-glow-primary`. Use for the big numbers in dashboards/stats.

### Animations
Keyframes registered in `tailwind.config.ts`:
- `accordion-down` / `accordion-up` — Radix Accordion expand.
- `pulse-glow` (`animate-pulse-glow`) — slow green box-shadow pulse for emphasis (e.g., featured CTAs).

## Typography

- Loaded from Google Fonts via `@import` in `src/index.css`.
- **Display**: `Rajdhani` (400/500/600/700) — applied via `font-display`. All headings (`h1`–`h6`) and stat numbers.
- **Body**: `Inter` (300–700) — applied via `font-body`. Default on `<body>`.

Tracking: `tracking-tight` on all headings (set in base layer). Use `tracking-[0.18em]` / `tracking-[0.22em]` for uppercase micro-labels (sidebar section titles, badges).

## Radius

`--radius: 0.5rem`. Tailwind exposes `rounded-lg`, `rounded-md` (= radius − 2px), `rounded-sm` (= radius − 4px). Use `rounded-md` for buttons, `rounded-lg` for cards.

## Component Conventions

Customized shadcn primitives in [`src/shared/ui/`](../../src/shared/ui/). When extending or building a new variant:

- **Buttons**: variants live in [`button-variants.ts`](../../src/shared/ui/button-variants.ts). Primary uses `bg-primary`. Avoid inline color classes on `<Button>`.
- **Cards**: prefer the `.card-gamer` utility for hero/featured cards; default `<Card>` for content blocks.
- **Inputs**: dark surface, primary-color focus ring (`--ring`).
- **Tabs / Dialogs / Sheets**: all dark by default. Don't override with `bg-white`.
- **Badges**: use semantic variants (`default`, `destructive`, `secondary`, `outline`). Custom plan badges use inline classes against tokens (no new variant added).

### Sidebar
[`src/widgets/hub-layout/ui/HubSidebar.tsx`](../../src/widgets/hub-layout/ui/HubSidebar.tsx) uses sidebar-scoped tokens and an `.active` marker (left vertical bar) on the active `NavLink`. Collapsed mode (16px width) renders icon-only with tooltips on the right.

## Icons

- **`lucide-react` only.** A single icon library keeps stroke weight and visual rhythm consistent.
- Standard sizes: `size={18}` for navigation, `size={16}` for inline UI, `size={13}` for chips/badges.

## Charts

- **`recharts` only.**
- Use `--primary` for the highlighted series and `--muted-foreground` for axes/grid. Tooltips: surface = `bg-card`, border = `border-border`, text = `text-foreground`.

## Loading and Feedback

- **In-page loaders**: simple animated text (`animate-pulse font-display`) in muted color for full-screen waits (see `FullScreenLoader` in `AuthGuards.tsx`).
- **Skeletons**: shadcn `<Skeleton />` from `shared/ui/skeleton.tsx`.
- **Toasts**: Sonner is the default. Use `toast.success`, `toast.error`, `toast.info`. The legacy shadcn `<Toaster />` is also mounted but Sonner is preferred for new code.

## Logo and Brand

`LogoMark` from [`src/shared/ui/Logo.tsx`](../../src/shared/ui/Logo.tsx). Used in:
- `HubSidebar` header (sized to collapse state).
- `AuthPageLayout` and `Landing`.

Brand wordmark: **"FC Career Hub"**, with a "Modo Carreira" eyebrow in uppercase tracked muted text.

## Accessibility

- All interactive primitives are Radix-based — keyboard and focus management are inherited.
- Focus ring uses `--ring` (= primary). Visible on all focusable surfaces.
- Tooltips are used on collapsed-sidebar icons to retain label discoverability.
- Color contrast not formally audited yet.

## Rules

❌ **Don't**
- Add a light theme or theme switcher.
- Introduce another icon set or UI kit.
- Hardcode colors (`#10b981`, `bg-green-500`). Use tokens.
- Use `bg-white` on overlays — it breaks the gamer aesthetic.

✅ **Do**
- Use tokens via Tailwind utilities.
- Reuse `.stat-highlight`, `.card-gamer`, `.glow-primary` for emphasis.
- Use Rajdhani (`font-display`) for numbers and headings; Inter for everything else.
