# 3.6.7 History

## Responsibility

Long-term view of the career: every club passed through, trophies lifted, and the season trail. This is the keepsake view of a save — the reason the product exists.

## Internal Architecture

```
features/history/
├── model/
│   ├── useClubStints.ts                  useClubStints, useChangeClub, useUpdateClubStint
│   └── useTrophies.ts                    useTrophies, useCreateTrophy, useDeleteTrophy
├── ui/
│   └── HistoryScreen.tsx                 stints timeline + trophies grid
└── index.ts
```

## Dependencies

- [`shared/api/client.ts`](../../../src/shared/api/client.ts) — `clubStintsApi`, `trophiesApi`, `competitionsApi`, `ApiClubStint`, `ApiTrophy`, `ApiCompetition`.
- [`features/saves/model/useSaves`](../../../src/features/saves/model/useSaves.ts) — to read the active save.
- `recharts` — optional sparkline per stint (e.g., trophies-per-season).

## Data Flow

### Stints
- `useClubStints(saveId)` → ordered list of stints. The current one has `isCurrent = true`.
- Changing club (`POST /club-stints`) goes through `useChangeClub`, but the typical entry point is `features/change-club` (see [3.6.8](3.6.8_Change_Club_New_Season.md)). The history screen is read-mostly.

### Trophies
- `useTrophies(saveId)` lists all trophies under the save (joined via `clubStintId`).
- `useCreateTrophy({ saveId, data: { competitionId, year } })` → POST. Server enforces uniqueness `(clubStintId, competitionId, year)`.
- `useDeleteTrophy({ saveId, trophyId })`.

## Local Domain Rules

1. A trophy belongs to a `ClubStint` (via `clubStintId`) and optionally to a `Competition`. The legacy `name` field exists but new trophies should use the `competitionId` relation.
2. A trophy is identified by `(clubStintId, competitionId, year)` — you cannot register the same competition twice for the same stint in the same year.
3. Closing the current stint (when changing clubs) marks `endYear` on the prior stint and creates a new stint with `isCurrent = true`. This is handled server-side by the change-club endpoint.

## Extension Points

- Career stat aggregates (total trophies, total seasons, goals over career).
- Hall-of-fame shareable image.
- Achievement system (first European cup, X clubs managed, …).
- Player legacy view (top scorer ever in this save, longest tenure, …).
