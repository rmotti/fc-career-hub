# 3.6.11 Dashboard

## Responsibility

Landing screen of the hub. Shows the executive snapshot of the active save: financial state, current-season summary, recent transfers, quick navigation to other modules.

## Internal Architecture

```
features/dashboard/
├── model/
│   └── useFinancialSnapshot.ts           derived computation across save + transfers
├── ui/
│   ├── DashboardScreen.tsx               page composition
│   └── StatCard.tsx                      glow-accented card primitive
└── index.ts
```

## Dependencies

- [`features/saves/model/useSaves`](../../../src/features/saves/model/useSaves.ts) — active save (budget, balance, current season).
- [`features/transfers/model/useTransfers`](../../../src/features/transfers/model/useTransfers.ts) — recent transfers ribbon.
- [`features/squad/model/usePlayers`](../../../src/features/squad/model/usePlayers.ts) — squad-size and OVR aggregates.
- [`features/stats/model/useTeamStats`](../../../src/features/stats/model/useTeamStats.ts) — season-form summary.
- [`shared/lib/currency.ts`](../../../src/shared/lib/currency.ts), [`finance.ts`](../../../src/shared/lib/finance.ts) — display formatting.
- `recharts` — small charts (form, financial trend).

## Data Flow

1. `DashboardScreen` reads the active save id and fans out queries: save, players, transfers (`season: "current"`), team stats.
2. `useFinancialSnapshot` derives net spend, current balance vs budget, and recent variation from the loaded data.
3. `StatCard` instances render the headline numbers with `.stat-highlight` glow.
4. Recent transfers and trophies cards offer deep-links to their respective modules.

## Local Domain Rules

1. The dashboard is **read-only**. No mutation happens from here.
2. Numbers come from the API where possible (using `*Formatted` fields). Client-side derivation is limited to aggregates that are pure functions of already-loaded data.
3. If the save isn't loaded yet, the screen renders skeletons — it must not gate the rest of the hub on its own data.

## Extension Points

- Persisted custom layout (user-arranged cards).
- Quick actions strip (advance season, add transfer) inline.
- Goals widget (track top scorer of the season).
- Historical chart (balance over seasons) — would benefit from a dedicated `/team-stats?aggregated=true` endpoint.
- Pinning a "favorite" player widget.
