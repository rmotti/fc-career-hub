# 3.6.10 Playbooks

## Responsibility

Configurable scoring profiles for the Scout module. A playbook is a set of weights (overall, age, historical fit, potential, market value, wage) and preferences (objective, ideal age range, max value/wage) that shape how `fitScore` is computed for a candidate.

## Internal Architecture

```
features/playbooks/
├── model/
│   └── usePlaybooks.ts                   usePlaybooks, useCreatePlaybook, useUpdatePlaybook, useDeletePlaybook
├── ui/
│   └── PlaybooksScreen.tsx               editor screen (CRUD + radar/bar weight visualization)
└── index.ts
```

`pages/hub/Playbooks.tsx` is a thin page wrapper that mounts `PlaybooksScreen`, served at `/scout/playbooks` (plan-gated).

## Dependencies

- `react-hook-form` + `zod` — schema for weight ranges (0–100).
- `recharts` — radar / bar visualization of weights.

## Data Flow

### Listing
- `playbooksApi.list(saveId)` returns `{ defaultPlaybook, playbooks }`. The default playbook is the fallback used by the Scout filters when no custom one is selected.

### CRUD
- `useCreatePlaybook({ saveId, name, weights, preferences, isDefault })`.
- `useUpdatePlaybook(playbookId, partial)`.
- `useDeletePlaybook(playbookId)`.
- Toggling `isDefault` on a playbook server-side flips it on others (only one default per save).

## Local Domain Rules

1. Playbooks are scoped to a save (`(saveId, name)` is unique).
2. `weights` keys: `overall`, `age`, `historicalFit`, `potential`, `marketValue`, `wage`. Each is a number; the server interprets them as relative weights (it normalizes).
3. `preferences.objective` ∈ `balanced | title | youth | rebuild` — surfaced as a high-level intent.
4. `preferences.idealAgeMin` / `idealAgeMax` create a soft penalty outside the range when computing fit.
5. `preferences.maxMarketValue` / `maxWage` create hard caps in the recommendation surface.
6. Exactly one playbook per save can have `isDefault = true`.

## Extension Points

- Preset playbooks per objective (one-click "Apply title playbook").
- Playbook diff view (compare two playbooks visually).
- Share playbooks across saves (currently saveId-scoped).
- Live preview of how a candidate scores under different playbooks.
