# 3.6.12 Tutorial

## Responsibility

Onboarding tours. Two flavors:

- **Save Select tutorial** — first-time experience after sign-up, walking through creating a save.
- **Hub tutorial** — interactive tour of the hub sidebar and main areas, runnable on demand.

## Internal Architecture

```
features/tutorial/
├── model/
│   ├── hubTutorialSteps.ts               step definitions for the hub tour
│   ├── saveSelectTutorialSteps.ts        step definitions for the save-select tour
│   ├── tutorialStyles.ts                 shared Joyride styles (matched to the dark theme)
│   └── tutorialUtils.ts                  storage helpers (seen / replayable flags)
└── ui/
    ├── HubTutorial.tsx                   Joyride wrapper mounted by HubLayout
    ├── SaveSelectTutorial.tsx            Joyride wrapper for /app
    ├── TutorialHelpButton.tsx            "help / replay tour" button
    └── TutorialTooltip.tsx               custom-styled tooltip component
```

## Dependencies

- `react-joyride` — driver of the step sequence.
- `localStorage` — completion flags per user/tour.
- Target DOM selectors: many tour steps depend on `data-tour="..."` attributes scattered across the app (e.g., `HubSidebar` sets `data-tour="hub-navigation"` and `data-tour="hub-new-season"`).

## Data Flow

1. On first visit to `/app` (no `saveSelectSeen:<userId>` flag), `SaveSelectTutorial` auto-starts.
2. On first entry to `/dashboard` (no `hubSeen:<userId>` flag), `HubTutorial` auto-starts.
3. Each step locates a target via `data-tour` selector and renders the custom `TutorialTooltip`.
4. Completion / dismissal writes the flag.
5. `TutorialHelpButton` resets the flag and restarts the tour on demand.

## Local Domain Rules

1. Tour state is fully client-side — completion flags don't sync across devices.
2. Steps target attributes that must exist in the DOM at the moment the tour fires; lazy-loaded screens require care.
3. The Scout section is included in the hub tour conditionally (skipped for FREE users).
4. The tour styles must match the dark theme — Joyride defaults are overridden in `tutorialStyles.ts`.

## Extension Points

- Centralize `data-tour` selectors in a typed constants module to prevent drift.
- Per-feature mini-tours (e.g., the first time a user opens Scout).
- Server-persisted completion (so a returning user on a new device skips the intro).
- A "what's new" mini-tour on version bumps.
