# 3.6.6 Stats

## Responsibility

Displays and edits team season stats per competition — wins, draws, losses, goals scored/conceded, league position, cup result.

## Internal Architecture

```
features/stats/
├── model/
│   └── useTeamStats.ts                   useTeamStats, useUpdateTeamStats
├── ui/
│   └── StatsScreen.tsx                   per-competition rows, edit-in-place
└── index.ts
```

## Dependencies

- [`shared/api/client.ts`](../../../src/shared/api/client.ts) — `teamStatsApi`, `ApiTeamStats`, `ApiCompetition`.
- [`shared/lib/competitions.ts`](../../../src/shared/lib/competitions.ts) — competition grouping and metadata.
- `recharts` — visual summaries (form chart, GD bar).

## Data Flow

### Listing
1. `useTeamStats(saveId, season?)` keys on `["teamStats", saveId, season]`.
2. Returns one row per competition for the requested season. Without `season`, returns all.

### Editing
1. `StatsScreen` opens an inline editor per row.
2. `useUpdateTeamStats({ saveId, statsId, data })` patches `goalsPro`, `goalsAgainst`, `wins`, `draws`, `losses`, `leaguePosition`, `cupResult`.
3. `onSuccess` invalidates `["teamStats", saveId]`.

## Local Domain Rules

1. Stats rows are auto-created server-side when:
   - A save is created (one row per competition of the club's country).
   - `currentSeason` is advanced via `PATCH /saves/:id`.
2. Each row is uniquely identified by `(clubStintId, competitionId, season)`.
3. `cupResult` / `europeanCupResult` / `nationalCupResult` is one of: `Campeao`, `Final`, `Semifinal`, `Quartas`, `OitavasOuFaseDeGrupos`, `Eliminado`, `NaoParticipou`.
4. `leaguePosition` is nullable — only meaningful for `CompetitionType = League`.
5. The `competition` reference is null for legacy rows from before competitions were normalized into the `Competition` table.

## Extension Points

- Historical comparison view (this season vs prior).
- Auto-derive `leaguePosition` from W/D/L when a final-table view exists.
- Visual season grid (matrix of seasons × competitions).
- Export stats as CSV / image.
