# 3.6.3 Squad

## Responsibility

Owns the squad roster: listing, creating, editing, releasing players, and updating their per-season stats. Also handles the bulk import of the FC26 dataset into a save.

## Internal Architecture

```
features/squad/
├── model/
│   └── usePlayers.ts                     usePlayers, usePlayer, useCreatePlayer,
│                                         useUpdatePlayer, useUpdatePlayerStats,
│                                         useImportFc26Players, useReleasePlayer
├── ui/
│   ├── SquadScreen.tsx                   roster table + filters
│   ├── PlayerModal.tsx                   create/edit dialog (RHF + Zod)
│   ├── PlayerViewModal.tsx               read-only detail with history + chart
│   └── StatsModal.tsx                    per-player stats edit
└── index.ts
```

## Data Flow

### Listing
1. `SquadScreen` calls `usePlayers(saveId, active, season, loaned)`.
2. The query keys on `["players", saveId, active, season, loaned]`.
3. Filter toggles update the args; React Query refetches on key change.

### Create / Edit
1. `PlayerModal` opens with optional `player` prop.
2. RHF schema validates name, position, age, status, ovr (1–99), shirtNumber, optional salary/marketValue/potential.
3. On submit → `useCreatePlayer` or `useUpdatePlayer`.
4. Server may return `SHIRT_NUMBER_CONFLICT` (409) — surfaced via `extractErrorMessage` and shown as a field-level or toast error.
5. `onSuccess` invalidates `["players", saveId]`.

### Stats update
- `StatsModal` patches goals/assists/yellow/red/matches/cleanSheets via `useUpdatePlayerStats`.
- Operates on the current season's stats row.

### Release
- `useReleasePlayer` → `DELETE /saves/:id/players/:id/release`. Removes the player from the active squad (the server may keep historical records linked).

### FC26 dataset import
- `useImportFc26Players({ saveId })` → bulk imports from the saved FC26 player dataset that the user has built up via Scout.
- Returns `{ imported, skipped, total }` — surfaced as a toast summary.

## Local Domain Rules

1. Position is one of: `GOL`, `ZAG`, `MEI`, `ATA`, `LD`, `LE`, `VOL`, `MC`, `ME`, `MD`, `PE`, `PD`, `SA`. Primary in `position`; alternates in `alternativePosition.positions[]`.
2. Status is one of: `Crucial`, `Important`, `Role`, `Sporadic`, `Promising`, `Loan`. `Loan` indicates the player is currently loaned (in or out).
3. `salary` is in thousands of €; `marketValue` in millions of €.
4. Shirt numbers are unique within an active squad. Conflicts surface as `SHIRT_NUMBER_CONFLICT` (HTTP 409).
5. `activeClubStintId = null` means the player is released (not on the active squad).
6. `ovrDelta` and `marketValueDelta` come from server-side comparison against the previous season — render them with sign and color.
